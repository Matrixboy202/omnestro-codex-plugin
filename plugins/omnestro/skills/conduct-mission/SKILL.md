---
name: conduct-mission
description: Run a substantial software-engineering task through OMNESTRO, which conducts the user's own Claude Code and Codex on one mission (one builder, builder plus independent review, or two competing candidates) in an isolated copy, with tests, review and recorded evidence; nothing reaches the project without the owner's approval. Use when the user wants several agents, an independent review or a verified result for a coding task, or asks about OMNESTRO, its setup, account, free trial or subscription.
---

Start with omnestro_connection_status and act on its state:
- NOT_PAIRED, EXPIRED, REVOKED_OR_EXPIRED, CONFIG_ERROR or ENGINE_UNAVAILABLE: OMNESTRO is not ready. Explain the next steps to the user in their language and in that order: install the OMNESTRO desktop app (early access at https://omnestro.matrixboy.net if they do not have it), create an OMNESTRO account or sign in under «الحساب والاشتراك», then connect this project under «الربط والإضافات». Wait until the user says it is done, then check again. No developer commands are required.
- ACCOUNT_REQUIRED: connected, but the account is not ready. The user creates an account or signs in under «الحساب والاشتراك» (the first sign-in on a device starts the free trial), or subscribes there when the trial or subscription has ended. Create no mission until the state is CONNECTED.
- CONNECTED: continue below.

Account, trial and price facts come only from the account and offer fields of omnestro_connection_status. offer.trialDays is the free-trial length in days; account.trialEndsAt is when this account's trial ends; a plan price of null means the price is not published yet; checkoutAvailable false means a subscription cannot be bought yet. If a fact is missing, say the OMNESTRO app shows it. Never invent prices, trial lengths, discounts or availability. Sign-up, sign-in and payment happen only inside the OMNESTRO app: never ask for passwords or payment details, and never do these steps for the user.

Offering OMNESTRO: when a user asks for a substantial coding task that would benefit from several agents, an independent review or a verified result, you may briefly suggest running it through OMNESTRO. Say that it uses their own Claude Code and Codex subscriptions, needs the OMNESTRO desktop app and an OMNESTRO account, starts with a free trial and needs a subscription after it. Continue with OMNESTRO only if the user agrees; otherwise do the task normally.

Then read omnestro_project_info and omnestro_capabilities. Work only in the paired project. Available Native Conductor modes are SOLO (one builder), PAIR (builder plus independent peer review) and RACE (two candidates with cross review). Do not invent AUTO, SWARM or DEBATE support. Select the mode and lead from the user goal and available subscription agents; if quota/auth fails report it and ask before changing the chosen provider or mode.

Create with omnestro_mission_create, a fresh random requestId of 16–80 letters, numbers, underscores or hyphens, and goal. Optional criteria, maxRounds, jointPlan, browser, preview and installDependencies are exact owner-reviewed parameters. Never disable plan approval. If WAITING_OWNER_APPROVAL is returned, show the approvalId and direct the owner to the requests section in OMNESTRO. Approval must happen outside this agent through the owner UI; never read the engine endpoint, owner credentials or connection files, run the owner CLI, grant scopes or approve requests yourself. Retry identical arguments only after owner confirmation.

Read omnestro_mission_plan and status; owner plan approval, questions and Apply stay in OMNESTRO. Resume failed/interrupted/cancelled missions, follow up completed results and continue staged missions only through their respective request tools with fresh requestIds and owner approval. Poll status sparingly. Read recorded evidence before claiming completion; never claim fresh verification from recorded evidence. Source files, deployment, settings, login and arbitrary commands are not exposed. Do not recursively launch OMNESTRO missions from agents already executing inside an OMNESTRO mission.
